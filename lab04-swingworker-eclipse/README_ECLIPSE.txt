LAB 4 - Java SwingWorker (Eclipse)
====================================

Java 17 + Maven project, package: vn.edu.eaut.lab4

Import into Eclipse:
1. File -> Import -> Maven -> Existing Maven Projects.
2. Chọn thư mục lab04-swingworker.
3. Finish, chờ Maven tải/cập nhật.
4. Run As -> Java Application -> App.java.
5. Menu hiện ra để chạy Bài 1 -> Bài 10.

Lưu ý:
- Bài 5/7/8/10 cần chọn file trên máy.
